# Sudanese Dialect Evaluation Rubric

Use this rubric to score model outputs. Ideal for both human raters and future automatic metrics.

## Scoring Dimensions (1–5)

### 1. Dialect Authenticity
| Score | Description |
|-------|-------------|
| 5 | Sounds completely natural to a native speaker of the target region |
| 4 | Mostly authentic, minor unnatural phrasing |
| 3 | Recognizably Sudanese but mixed with other dialects or MSA |
| 2 | Some Sudanese words but overall foreign |
| 1 | Not Sudanese (Egyptian, Levantine, Gulf, or pure MSA) |

### 2. Regional Accuracy
| Score | Description |
|-------|-------------|
| 5 | Correctly uses vocabulary and style of the requested region |
| 4 | Mostly correct region with small slips |
| 3 | Generic Sudanese, not clearly regional |
| 2 | Wrong region or mixed regions |
| 1 | Completely wrong regional markers |

### 3. Fluency & Naturalness
| Score | Description |
|-------|-------------|
| 5 | Flows like natural spoken Sudanese |
| 4 | Very readable and natural |
| 3 | Understandable but slightly stiff |
| 2 | Awkward or broken |
| 1 | Incoherent |

### 4. Cultural Appropriateness
| Score | Description |
|-------|-------------|
| 5 | Correct cultural references, tone, and politeness |
| 4 | Mostly appropriate |
| 3 | Neutral but misses nuance |
| 2 | Mildly inappropriate or odd |
| 1 | Culturally wrong or offensive |

### 5. Helpfulness / Task Success
| Score | Description |
|-------|-------------|
| 5 | Fully answers the user request in authentic dialect |
| 4 | Mostly answers well |
| 3 | Partial answer |
| 2 | Weak answer |
| 1 | Fails the request |

## Overall Score
Average of the five dimensions.

**Target for “goal reached”**: Average ≥ 4.2 across a diverse test set of 100+ examples rated by native speakers from different regions.
